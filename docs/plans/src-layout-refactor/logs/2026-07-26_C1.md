# TICKET-C1 — Assert the distribution stays clean

Date: 2026-07-26 · Branch: `feat/10-src-layout-refactor` · Commit: `fc953f5` · Status: DONE

## What shipped

`tests/test_packaging.py` — four tests reading the **built wheel**, not the source
tree, since a stray hatch `packages`/`artifacts` entry can re-include a file that the
`src/` layout alone would have kept out. Stdlib only (`tomllib`, `zipfile`,
`configparser`); no new dependency.

Two design choices worth keeping:
- Tooling module names are **derived** from `tools/pyvartoolbox_docs/`, not hardcoded,
  so a third tool is covered automatically.
- Both derived sets assert non-empty ("this test proves nothing"), so the tests cannot
  silently become vacuous — the failure mode that makes a regression guard worthless
  without anyone noticing.

## Defect found and fixed during verification

`_console_scripts` parsed `entry_points.txt` with a default `ConfigParser`, which
**lower-cases option names**. Console-script names are case-sensitive, so any script
not already lower-case would be mangled and
`test_declared_console_scripts_are_what_ships` would fail for a reason unrelated to
packaging. Demonstrated concretely:

```
default configparser : {'mytool-run': 'pkg.mod:main'}   <- mangled
optionxform=str      : {'MyTool-Run': 'pkg.mod:main'}   <- preserved
```

Invisible today because `pyvartoolbox-replicate` is all lower-case, so every gate
passed regardless. Fixed with `parser.optionxform = str` plus a comment saying why.
All four behaviours re-verified after the fix.

## Follow-up raised: TICKET-C3 — this guard does not run in CI

`.github/workflows/ci.yml:20-22` runs `uv sync`, `ruff`, `pytest` and **never
`uv build`**. `dist/` therefore does not exist in CI, so all four tests skip on every
pull request, on all three Python versions, while the suite reports green.

C1's Problem statement — "nothing stops the next dev-only module re-entering the wheel,
because nobody inspects a built artifact" — is therefore *still true* after C1 ships,
in the one place that checks every change. The skip-when-unbuilt behaviour is correct
and was specified by the ticket; the gap is that nothing in CI builds.

Not fixed inside C1: C1's declared Files are `tests/test_packaging.py` only, and
silently widening a ticket to touch `ci.yml` is the same mistake that let A1 absorb A2.
Filed as TICKET-C3, whose Done-when requires a **CI run URL showing 4 passed, 0
skipped** — local verification cannot prove a CI-specific defect.
