# TICKET-C3 — Make the packaging guard actually run in CI

Date: 2026-07-26 · Branch: `feat/10-src-layout-refactor` · Commit: `acd1889` · Status: DONE

## Origin

Not in the original plan. Found by the dispatcher while verifying C1: every one of
C1's gates passed locally, yet `.github/workflows/ci.yml` ran `uv sync`, `ruff` and
`pytest` and **never `uv build`**. `dist/` therefore never existed in CI, so all four
packaging tests skipped on every pull request across all three Python versions while
the suite reported green. C1's Problem — "nobody inspects a built artifact" — was
still true after C1 shipped, in the one place that checks every change.

## What shipped

A `uv build` step in `.github/workflows/ci.yml`, ordered after `ruff` and before
`pytest`, with a comment explaining why removing it would silently disable the guard
rather than break anything visibly. The skip-when-unbuilt path is untouched, so the
suite stays runnable locally without building.

## Done-when verification

The ticket required **CI evidence**, not a local proxy — the whole defect was
CI-specific, and a local run only proves the step is well-formed.

- Run: https://github.com/r-uben/pyvartoolbox/actions/runs/30197139066 — **success**
- `258 passed, 18 warnings` on **3.11, 3.12 and 3.13**, with **zero skipped**
- Before this fix the same run would have reported `254 passed, 4 skipped`; the four
  packaging tests now execute
- `ruff check` clean on all three versions
- YAML parsed locally to confirm step ordering (`uv sync` → `ruff` → `uv build` →
  `pytest`) before pushing

## Why this was filed rather than folded into C1

C1's declared Files were `tests/test_packaging.py` only. Silently widening a ticket
mid-dispatch to touch `ci.yml` is the same error that let A1 absorb A2 earlier in this
plan and left the board overstating what had been reviewed. Filing it cost one commit
and kept the record honest.

## The generalisable point

A test that skips is indistinguishable from a test that passes in a summary line, and
CI is where that distinction stops being cosmetic. C1 was *correct* and *complete* and
still guarded nothing for as long as the build step was missing. Worth checking, for
any test gated on a build artifact, that the pipeline actually produces the artifact.
